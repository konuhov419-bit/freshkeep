# ДЗ 1. Сравнительная таблица AI-агентов для разработки

Задача: разработка MVP мобильного приложения FreshKeep (см. отчёт `hw1_report.md`). Цены сверены с официальными страницами 15.10.2026, оценки — экспертные (1–5, где 5 — лучше), а не результат бенчмарков.

## 1. Фактические данные

| Инструмент | Тип | Цена (индивидуально) | Модель оплаты | Доступ к проекту |
|---|---|---|---|---|
| **Lovable** | Cloud | Free; Pro от $25/мес за 100 кредитов; Business от $50/мес | Кредиты за промпт; на Free 5 кредитов в день (до 30 в месяц) | Проект в облаке; GitHub sync на всех планах; скачать код — только Pro и выше |
| **Bolt.new** | Cloud | Free; Pro $25/мес; Teams $30 за участника | Токены: Free 300K в день и 1M в месяц; Pro от 10M в месяц | Проект в облаке (браузер) |
| **Replit Agent** | Cloud | Starter бесплатно; Core ($20 кредитов в месяц; $204 в год); Pro $100/мес | Кредиты, оплата по сложности запроса | Проект в облачной среде Replit |
| **Cursor** | IDE | Страница тарифов (15.10.2026): Free; Plus $8; Premium $30; Super $100; Ultra $200 | Пулы использования; сторонние модели по цене API на Premium и выше | Локальные файлы всего репозитория |
| **GitHub Copilot** | IDE-плагин | Free; Pro $10; Pro+ $39; Max $100 | «AI-кредиты» (1 кредит = $0,01); на платных тарифах безлимитные inline-подсказки | Открытые файлы и репозиторий в VS Code, JetBrains и др. |
| **Claude Code** | CLI/IDE | В составе Claude Pro ($20/мес, $17 при оплате за год) и Max (от $100/мес); Free — не включён | Лимиты подписки (или оплата по API) | Локальные файлы репозитория, запуск команд и тестов |
| **Aider** | CLI | Сам инструмент бесплатный (open source), платите за API выбранной модели | Оплата провайдеру модели; можно подключить локальную модель | Локальный репозиторий, карта кода (repo map), авто-коммиты в git |

## 2. Оценки по критериям (1–5)

| Критерий | Lovable | Bolt.new | Replit Agent | Cursor | Copilot | Claude Code | Aider |
|---|---|---|---|---|---|---|---|
| Доступ к контексту проекта | 3 | 3 | 4 | 5 | 4 | 5 | 4 |
| Скорость генерации кода | 5 | 5 | 4 | 4 | 4 | 3 | 3 |
| Качество кода | 3 | 3 | 3 | 4 | 4 | 5 | 4 |
| Стоимость (5 = дешевле для задачи) | 3 | 3 | 3 | 3 | 5 | 3 | 4 |
| Безопасность данных | 2 | 2 | 2 | 4 | 4 | 4 | 4 |
| Удобство интеграции в процесс | 2 | 2 | 4 | 5 | 5 | 4 | 3 |

### Обоснование оценок

- **Контекст.** IDE и CLI-агенты видят весь локальный репозиторий; Cursor и Claude Code индексируют код и могут запускать команды. Cloud-агенты работают внутри собственного проекта в облаке, без доступа к локальным файлам.
- **Скорость.** Cloud-генераторы быстрее всего выдают рабочий прототип из одного промпта; Claude Code и Aider работают медленнее, так как выполняют несколько шагов (правка, запуск тестов, исправление).
- **Качество.** Максимум у агентов с запуском тестов и сильными моделями (Claude Code, Cursor, Copilot). У cloud-агентов код хорош для прототипа, но труднее поддерживать.
- **Стоимость.** Copilot Pro самый дешёвый платный вариант ($10); у Cursor цены на странице тарифов выше и сложнее; Aider бесплатен, но платный API; у cloud-агентов расход кредитов трудно предсказать.
- **Безопасность.** Cloud-агенты хранят код и данные у вендора. У Cursor есть Privacy Mode (при его включении обещано не обучаться на данных), SOC 2 Type II и ISO 27001. IDE/CLI-агенты отправляют вендору только контекст запросов, а Aider позволяет подключить локальную модель.
- **Интеграция.** Cursor и Copilot встроены в редактор и Git; Replit даёт готовое окружение; у Lovable/Bolt экспорт кода и работа вне платформы ограничены.

## 3. Взвешенный итог

Веса отражают требования проекта (медленно меняющийся код с тестами, бюджет до $20 в месяц, работа с локальным репозиторием): контекст 25%, качество 25%, стоимость 15%, безопасность 15%, интеграция 10%, скорость 10%.
